## 📋 About

Personal portfolio website showcasing my projects, skills, and experience. Built as a single-page static site with modern dark-themed UI, smooth animations, and responsive design.

## ✨ Features

- **Dark glassmorphism** design with gradient accents
- **Animated hero** section with rotating role titles
- **Project showcase** with category filters (ML, Web, Simulation)
- **Skills grid** organized by domain
- **Experience timeline** highlighting HPE internship and hackathon wins
- **Responsive layout** for all screen sizes
- **Scroll-reveal animations** for smooth UX

## 🛠️ Tech Stack

| Layer      | Technology                                          |
| ---------- | --------------------------------------------------- |
| Structure  | HTML5                                               |
| Styling    | CSS3 (custom properties, grid, flexbox, animations) |
| Typography | Google Fonts (Sora, Inter)                          |
| Deployment | GitHub Pages + GitHub Actions                       |

## 🚀 Deployment

This portfolio is deployed automatically via GitHub Actions. Any push to `main` triggers the [deploy-portfolio.yml](../.github/workflows/deploy-portfolio.yml) workflow, which publishes the `00-Portfolio/` folder to GitHub Pages.
